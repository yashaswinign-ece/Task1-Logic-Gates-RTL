Task 1: Logic Gates & RTL Simulation

Overview

Designed, simulated, and verified basic combinational logic gates (AND, OR, XOR, NAND) and a 2:1 multiplexer using Verilog HDL.

Repository Contents

* "design.sv" - Verilog RTL implementation for combinational gates and 2:1 MUX.
* "testbench.sv" - Testbench applying all 8 input combinations and generating VCD waveform dump.
* "Screenshot 2026-11-09 191217.png" - EPWave output screenshot verifying functional correctness.

Tools Used

* Simulator: Icarus Verilog (via EDA Playground)
* Waveform Viewer: EPWave
